Get your bot running

Use bots only on servers you own or where the rules allow AFK bots.

1. Point the bot at your server

Set MC_HOST, MC_PORT and BOT_USERNAME as environment variables, or edit settings.json (server and accounts). Cracked servers use type offline; premium servers use microsoft and print a device code in the terminal on first login.

2. Secure the dashboard

Set DASHBOARD_PASSWORD and SESSION_SECRET. Without them the dev password admin123 is used.

3. Switch on AI (optional)

Add at least one of GEMINI_API_KEY, GROQ_API_KEY, OPENAI_API_KEY. In game, type .ai what is a creeper?. Enable the autonomous brain with ai_brain.enabled or the AI tab.

4. Connect Discord (optional)

Create a bot in the Discord developer portal, enable Message Content Intent, invite it with the bot and applications.commands scopes, then set DISCORD_BOT_TOKEN, DISCORD_GUILD_ID and (for the chat bridge) DISCORD_BRIDGE_CHANNEL_ID. Add role names or ids to discord.adminRoles.

5. Pick where it runs

  • Railway: deploy the GitHub repo, add the variables, attach a volume at /app/data.
  • Render: New Blueprint from the repo (uses render.yaml). The free plan sleeps; the built-in keep-alive pings /ping.
  • GitHub Actions: headless; add secrets, run the Run Bot workflow, control it from Discord.

Full instructions, config keys and the test checklist are in README-v3.md.
